# @voxelithic/interfaces

TypeScript types, ABIs, and deployed addresses for Voxelithic contracts on Robinhood Chain (4663).

## Install

```bash
npm install @voxelithic/interfaces
```

## Usage

```typescript
import { ROUTER, ROUTER_V4, QUOTER, QUOTER_V4 } from '@voxelithic/interfaces'
import type { Route, Hop, PoolKey } from '@voxelithic/interfaces'
```

## Exports

- `addresses.ts` — deployed contract addresses
- `tokens.ts` — known token addresses and metadata
- `types.ts` — TypeScript interfaces
